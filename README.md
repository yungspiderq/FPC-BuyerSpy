# 👁 BuyerSpy — Шпион покупателя

Плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) **v0.1.17+**

Показывает, **что покупатель смотрит на FunPay прямо сейчас** — ваш лот, категорию
или лот конкурента. Использует официальный виджет FunPay «сейчас смотрит»
(метод `get_buyer_viewing` в FunPayAPI — тот же, что виден продавцу в веб-чате).

Зачем: если покупатель перед покупкой (или сразу после оплаты) разглядывает лот
конкурента — вы узнаете об этом первым и сможете предложить лучшие условия,
скидку или бонус, чтобы закрыть сделку.

## Возможности

- 🛒 **Авто-шпионаж при новом заказе** (включён по умолчанию) — уведомление
  «👁 Покупатель сейчас смотрит: <ссылка и название>» с контекстом заказа.
- 💬 **Авто-шпионаж по первому сообщению в чате** (по умолчанию выключен) —
  как только новый покупатель написал, плагин посмотрит, что он разглядывает.
  Один раз на чат — без спама.
- 🔎 **Ручная проверка**: команда `/spy <ID покупателя>` или просто `/spy`
  (последний покупатель). ID берётся из ссылки на профиль: `funpay.com/users/<ID>/`.
- 🔄 Кнопка «Проверить еще раз» под каждым результатом — покупатель мог
  переключиться на другой лот.
- В результате: название просматриваемого лота, ссылка, ID лота, подсказка
  «если это конкурент — предложите лучшие условия».
- 💾 Настройки: `storage/plugins/buyer_spy/settings.json`.

## Установка

```bash
cd /home/fpc/FunPayCardinal
wget https://raw.githubusercontent.com/yungspiderq/FPC-BuyerSpy/main/buyer_spy.py -O plugins/buyer_spy.py
sudo systemctl restart FunPayCardinal@fpc
```

или отправьте файл боту в Telegram → `🔌 Плагины` → `➕ Добавить плагин`.

## Использование

- Команда **`/spy`** — меню плагина (переключатели режимов, «Что смотрит последний
  покупатель?»).
- **`/spy 1234567`** — проверить конкретного покупателя.

| Кнопка меню | Действие |
|---|---|
| 🛒 Авто-шпионаж при заказе: ВКЛ/ВЫКЛ | Проверять покупателя при каждом новом заказе |
| 💬 По первому сообщению: ВКЛ/ВЫКЛ | Проверять при первом сообщении нового чата |
| 👀 Что смотрит <последний покупатель>? | Ручная проверка последнего |

### Пример уведомления

```
👁 Шпион покупателя (новый заказ #A1B2C3D4)

buyer1 сейчас смотрит:
Аккаунт Steam с играми (ссылка)

🔢 ID лота: 12345678
🏷 lot-common

💡 Если это лот конкурента — самое время предложить покупателю лучшие условия в чате.
```

## Важно знать

- Данные «сейчас смотрит» отдаёт сам FunPay: если покупатель ничего не смотрит
  (или закрыл страницу), плагин честно сообщит «не смотрит конкретный лот».
- Каждый запрос шпионажа — один легковесный запрос к FunPay (тот же runner-канал).
  Автоматические режимы срабатывают максимум раз на заказ/чат — нагрузки нет.
- Уведомления идут через тип «Прочие уведомления (плагины)».
- Плагин работает в связке с [FPC-OrdersDashboard](https://github.com/yungspiderq/FPC-OrdersDashboard):
  увидев, что покупатель сравнивает с конкурентом, напоминание/скидку можно отправить
  прямо из дашборда заказов.

## Состав репозитория

- `buyer_spy.py` — плагин (класть в `plugins/`).
- `tests_plugin_buyer_spy.py` — тесты (38 проверок на моках: форматирование,
  авто-режимы, анти-спам, обработка ошибок API, команды, весь Telegram-UI, настройки).
  Запуск из корня FunPayCardinal:
  ```bash
  cp tests_plugin_buyer_spy.py /path/to/FunPayCardinal/
  cd /path/to/FunPayCardinal && pip install -r requirements.txt && python3 tests_plugin_buyer_spy.py
  ```
